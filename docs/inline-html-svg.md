# 内嵌 HTML 与 SVG 支持范围

Nomo 允许在 Markdown 中直接书写 HTML。为了保证编辑结果与源文件一致，只有能被编辑器
完整表示的结构才会转成可编辑卡片，其余内容按原文保留，不会被执行或改写。

## 可编辑的 HTML 块

满足以下全部条件时，HTML 块会在编辑器中显示为可编辑卡片：

- 只有一个根元素，且根元素是 `<section>` 或 `<div>`；
- 根元素只带 `class` / `id` 属性，没有 `style`、事件属性或其它自定义属性；
- 根元素内部只能是行内内容，不能再嵌套 `<div>`、`<section>` 或其它块级元素；
- 内部标签都在白名单内，且属性组合能被无损保存。

支持的行内标签：

| HTML | 编辑器中的含义 |
| --- | --- |
| `strong` / `b` | 加粗 |
| `em` / `i` | 斜体 |
| `s` / `del` / `strike` | 删除线 |
| `u` | 下划线 |
| `mark` | 高亮 |
| `code` | 行内代码 |
| `a` | 链接（`href`、`title`、`id`、`name`） |
| `sup` / `sub` | 上标 / 下标 |
| `span` | 无属性文字，或只含一条 `style="color: …"` 的颜色文字 |
| `br` | 软/硬换行 |
| `img` | 图片（`src`、`alt`、`title`、`width`、`align`） |

数学公式、行内批注、脚注引用这类由 Nomo 自身生成的节点也会被识别并保持可编辑。

图片地址只接受相对路径、`http(s)`、`asset:`、`tauri:`、`file:`、`blob:` 以及
`data:image/...;base64` 形式；`javascript:` 等协议会被拒绝。

## 原文回退

下列内容不会被当作可编辑 HTML：

- 多个根元素、嵌套块级元素，或根元素带无法表示的属性；
- `<script>`、`<style>`、`<iframe>`、`<form>`、`<svg>`、`<object>` 等标签；
- 含事件处理属性、非白名单属性或无法安全往返的内联标签；
- 无法闭合或结构不完整的 HTML。

回退内容在编辑器中以源码形式显示（不是运行结果），保存时保持原文；渲染导出时会经过
清洗，移除脚本、事件属性和危险 URL。

## 源码编辑器的补全

在 Markdown 源码模式下，以下位置会弹出 HTML5 / CSS3 补全：

- `<div`、`</di` 等标签名位置；
- `<div cla` 等属性名位置；
- `style="…"` 内部的 CSS 属性与常用属性值；
- `<style>` 块以及 ` ```html ` / ` ```css ` 围栏代码块内部。

用 ↑/↓ 切换候选，Enter 或 Tab 接受，Esc 关闭。普通正文里的 `<` 和冒号不会触发补全。
